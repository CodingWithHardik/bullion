# Bullion

Bullion is a trading game with virtual cash. Buy low sell high and see how your market instincts hold up in three minutes

## Getting Started

### Prerequisites

- Nodejs Installed

- Package Installation 
```npm install```

### Deployment
- Development
```
npm run dev
```
- Production
```
npm run build
npm run start
```
